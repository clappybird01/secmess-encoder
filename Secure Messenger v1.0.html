3. Инструкция по обмену

🔒 PFS активировано: AES-ключ никогда не передаётся по сети! Он вычисляется локально на основе вашего приватного ключа и публичного ключа друга.

📋 Правильный порядок:

  1. Оба участника генерируют ECDH-ключи
  2. Обмениваются публичными ключами
  3. Сравнивают отпечатки по защищённому каналу
  4. Если отпечатки совпадают - вычисляют общий AES-ключ
  5. Начинают безопасную переписку
⚠️ Важно: Для каждого нового сеанса создавайте новые ECDH-ключи! Это обеспечивает Perfect Forward Secrecy.
Технические детали безопасности:
• ECDH с кривой P-384 (384-битная безопасность)
• HKDF с уникальной солью для каждой пары ключей
• AES-GCM с AAD и timestamp (защита от подмены контекста)
• Проверка времени: предупреждение о старых (>5 мин) и будущих сообщениях
• Неэкспортируемые ключи (защита от извлечения)
• Отпечатки: SHA-512 → Base64URL (96 бит) + 6 эмодзи (30 бит)

✍️ Цифровые подписи Ed25519

🛡️ Аутентификация сообщений: Ed25519 позволяет подтвердить авторство каждого сообщения. Собеседник сможет убедиться, что сообщение действительно отправлено вами и не было изменено.

📝 Как использовать (ECDH PFS + Ed25519):
1. Сгенерируйте ECDH ключи и обменяйтесь публичными ключами с другом
2. Сгенерируйте ключи подписи Ed25519 и обменяйтесь публичными ключами подписи
3. Сравните отпечатки обоих ключей по защищённому каналу
4. Если отпечатки совпадают — ключи подлинные, вычислите общий AES-ключ
5. Используйте AES-256-GCM с AAD и подписями Ed25519 для переписки и файлов
6. Для каждого нового сеанса создавайте новые ECDH-ключи (Ed25519 можно переиспользовать)
