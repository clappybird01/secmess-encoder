# Secure Messenger
Шифратор для конфиденциальных переписок, работающий локально в браузере через JavaScript и библиотеки Libsodium, noble-post-quantum.

## 📝 Немного о проекте
Проект разрабатывается энтузиастом для изучения цифровой безопасности, шифрования и защиты данных. Некоторые функции и особенности:
- **Простота установки и использования:** для работы с веб-приложением нужно лишь наличие современного браузера.
- **Конфиденциальность:** весь код выполняется локально на устройстве. Ваши данные никуда не передаются сами.
- **Интерфейс с инструкциями:** несколько цветовых тем на выбор (светлые и тёмные), ориентированные на удобство. Внешний вид ориентирован на компьютеры и телефоны, чтобы использовать веб-приложение можно было где угодно. Также присутствуют подсказки по использованию.
- **Актуальные протоколы для безопасности:** строгая политика Content Security Policy (CSP), использование проверенных и современных протоколов для шифрования сообщений и вычисления общего ключа.
- **Perfect Forward Secrecy (PFS):** алгоритм Double Ratchet с одноразовыми публичными ключами, которые вместе обеспечивают идеальную безопасность и секретность сообщений.
- **Подходит под большинство задач:** шифратор позволяет обмениваться текстом, файлами любого формата, голосовыми сообщениями без нужды в сторонних программах.
- **Пост-квантовая криптография:** скрипт создаёт гибридные ключи с протоколами X25519 и ML-KEM, предотвращая потенциальное раскрытие переписки в будущем.

## Установка и использование
⚠️ Рекомендуется использовать только самые свежие и новые версии, где закрываются уязвимости и добавляются новые функции.
Перейдите в раздел Releases и скачайте архив .zip. Распакуйте архив любым ПО. В появившейся папке откройте файл с расширением .html через любой браузер. Версии ниже 4.0 не нуждаются в распаковке архива: нужно только скачать файл .html и запустить его. Убедитесь, что все сопутствующие файлы .js лежат в одной папке с .html.

Чтобы начать общение, сгенерируйте ключи на главной странице и обменяйтесь ими с собеседником. Начиная с версии 6.0, после обмена ключами одному из собеседников нужно передать специальный cipherText другому для завершения обмена ключами. После этого оба участника получат общий ключ для переписки. Для предотвращения атаки MITM (Man-In-The-Middle) с версии 6.1 внедрена обязательная верификация собеседника: вы можете сверить отпечатки ключей (что нужно делать по доверенному каналу связи) или использовать подписи Ed25519, которые можно сравнить лишь один раз и затем использовать многократно без проверки. Убедитесь, что ваши приватные ключи подписи надёжно сохранены и никто не может их украсть!

**Использование на устройствах под iOS может быть затруднено из-за ограничений системы.** Рекомендуется использовать приложение через [GitHub Pages](https://clappybird01.github.io/secmess-encoder/): код из GitHub откроется в браузере и будет исполняться локально.

**❗Важно! После обновления/закрытия HTML-страницы переписка и ключи не сохраняются!**

## 🛠 Стек технологий
* HTML5 / CSS3 (Ванильный CSS с переменными)
* Vanilla JavaScript (ES6+)
* Криптография: libsodium, noble-post-quantum, Web Crypto API

**Криптографические детали:**
- Обмен ключами: `X25519` с кривой `Curve25519` (libsodium crypto_kx) совместно с `ML-KEM-768`
- Гибридный миксинг: `BLAKE2b — Final = H(S_X25519 || S_MLKEM768)`, 32 байта
- Шифрование: `XChaCha20-Poly1305 (IETF)` с AAD и timestamp
- Подписи: `Ed25519` (libsodium-detached, вкладка «Подписи»)
- Защита от replay: проверка времени сообщения (>5 мин = предупреждение)
- Защита от подмены контекста: AAD разделён для сообщений и файлов
- Изолированные ключи шифрования (защита памяти внутри WebAssembly)
- Отпечатки: `SHA-512` → `Base64URL` (96 бит) + 6 эмодзи (30 бит энтропии)
- Perfect Forward Secrecy: каждая сессия — новые гибридные ключи

**На данный момент алгоритм подписей подвержен пост-квантовым компьютерам.** Гибридные ключи подписи планируются в будущем.
